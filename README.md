# Smart Home Project

Custom smart home ecosystem built with Home Assistant, ESPHome and AI integrations.

This repository contains my personal smart home setup focused on:
- modern dashboard design
- automation
- AI integrations
- server monitoring
- self-hosting
- smart room control
